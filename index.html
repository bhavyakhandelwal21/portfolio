MediKiosk

A multilingual clinical-intake prototype with patient records, a conversational assistant, and OCR for prescriptions and reports.

View on GitHub ↗

Next.js / ReactFastAPIGemini FlashPaddleOCRSQLite
Project details
Problem
Patient information can be scattered across conversations, recordings, prescriptions, and PDFs, making it hard to review before a consultation.
How it works
MediKiosk combines symptoms, audio, prescriptions, PDFs, and chat responses into a multilingual medical history and a summary for the doctor.
Key features
  • Upload prescriptions, PDFs, images, or audio, or type in symptoms.
  • Extract text from printed and handwritten prescriptions with OCR.
  • Generate multilingual medical summaries with AI.
  • Collect patient history through a chatbot.
  • Store previous consultations to maintain a continuous medical history.
  • Prepare a structured summary for doctors.
  • Flag symptoms that may need emergency attention.
  • Protect account access with login and password hashing.
My contribution
I built the OCR feature that extracts text from prescriptions and medical reports for use in the patient’s medical history.

DECISION SUPPORT · HEALTHCARE

MediRoute

An inventory prototype that surfaces medicine shortages and expiry risks, then suggests redistribution and delivery routes.

Worked on MediRoute at HackBVP 8.0, a 24-hour hackathon hosted by Bharati Vidyapeeth’s College of Engineering, New Delhi.

View on GitHub ↗

ReactFastAPIPandasLeafletSQLite
Project details
Problem
Medicine shortages and stock nearing expiry can lead to stockouts, wasted supplies, and urgent replacement costs.
How it works
MediRoute takes inventory and usage data from manual entries or uploaded PDFs, checks the records, estimates demand, and flags potential shortages and expiry risks. It explains suggested transfers from facilities with eligible surplus or recommends reordering. It can show transfer routes on a map. Staff review the data and recommendations before acting.
Key features
  • Enter medicine inventory manually or upload a PDF.
  • Forecast demand from usage patterns.
  • Flag potential stockouts, expiry risks, and data issues.
  • Suggest medicine transfers and reorders, with map routes for transfers.
  • Explain why each recommendation was made.
  • Review blood-bank inventory and suggest transfers.
  • Run the prototype locally in offline mode.

DEFI · SEPOLIA

PoolWise

An interactive DeFi app to compare liquidity-pool returns with holding, connect a MetaMask wallet, and practice swaps and liquidity on Sepolia.

View on GitHub ↗

SolidityHardhatethers.jsMetaMaskSepolia
Project details
Problem
Liquidity providers often struggle to see how token price changes affect their returns and when those changes can lead to impermanent loss.
How it works
PoolWise compares holding tokens with providing liquidity as prices change. A connected Sepolia wallet lets users view live pool data and practice swaps and liquidity actions using testnet tokens.
Key features
  • Calculate estimated impermanent loss as token prices change.
  • Graph the value of holding tokens versus providing liquidity.
  • Practice token swaps and liquidity actions in the Sepolia wallet lab.
  • Inspect live pool reserves and spot prices.
